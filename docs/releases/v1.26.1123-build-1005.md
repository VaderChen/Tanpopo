## 繁體中文

### Inkling-2-Mini

在「模型下載 → 常用模型 → 30B 級」可選四種量化。GGUF 提供 Unsloth 主線相容的 **UD-Q4_K_XL**、**UD-Q8_K_XL**，並保留 **IQ4_NL**。選取項目會指定對應檔名。以 llama-server 啟動，圖片輸入需搭配相符的 mmproj。

Apple Silicon 的原生 Swift mlx-server 提供 **4-bit MLX** 和 **8-bit MLX**。下載完整模型目錄後，以自動類型啟動即可進行文字與圖片推論。權重分別約 17.31 GB、18.09 GB，均保留混合精度專家。推論另需記憶體。安裝包不含權重。

### 驗證與升級

M4 Pro、64 GiB 上的兩個 MLX 版本都通過完整權重 SHA-256 核對、文字回答、紅色圖片辨識與 SSE 串流。macOS 上的 GGUF 完整推論驗證使用 IQ4_NL 與 Q8_0 mmproj。此次 Inkling 支援範圍為單機標準解碼。Fast GGUF、TCP Ring／RDMA、DFlash 與 MTP 不在此模型的支援範圍。Windows 和 Linux 的本版安裝包未做實機端到端推論驗收。

從「系統設定 → 關於」選擇「更新並重新啟動」，或下載下方的 macOS Apple Silicon DMG、Windows x64 MSI、Linux x64 ZIP。Linux 首次安裝需建置隨附的 Vulkan 引擎。可用 SHA256SUMS 核對下載檔案。[模型指南](https://github.com/VaderChen/Tanpopo/blob/v1.26.1123-build-1005/docs/INKLING2-MINI.md) · [驗證記錄](https://github.com/VaderChen/Tanpopo/blob/v1.26.1123-build-1005/docs/validation/inkling2-mini-smoke-2026-11-23.json)

## English

### Inkling-2-Mini

Open **Model downloads → Popular models → 30B class** to choose a quantization. GGUF adds Unsloth’s mainline-compatible **UD-Q4_K_XL** and **UD-Q8_K_XL** alongside **IQ4_NL**. Each entry selects its exact file. Use llama-server and load the matching mmproj for image input.

On Apple Silicon, the native Swift mlx-server supports **4-bit MLX** and **8-bit MLX**. Download the complete model directory and start with automatic model detection for text or images. The weights are about 17.31 GB and 18.09 GB respectively. Both retain mixed-precision experts and require additional memory for inference. Download weights separately from the installer.

### Verification and upgrade

Both MLX checkpoints passed full weight SHA-256 verification, text generation, red-image recognition and SSE streaming on an M4 Pro with 64 GiB. The full GGUF inference check on macOS used IQ4_NL with a Q8_0 mmproj. Inkling supports standard single-machine decoding. Fast GGUF, TCP Ring/RDMA, DFlash and MTP are outside the supported scope for this model. End-to-end inference with this release’s Windows and Linux installers has not been tested on those platforms.

Choose **System settings → About → Update and restart**, or download the macOS Apple Silicon DMG, Windows x64 MSI or Linux x64 ZIP below. The Linux installer builds the bundled Vulkan engine on first installation. Verify the download against SHA256SUMS. ## 日本語

### Inkling-2-Mini

モデルのダウンロード画面で、よく使うモデル一覧の **30B クラス**から量子化形式を選べます。GGUF は従来の **IQ4_NL** に加え、Unsloth のメインライン互換版 **UD-Q4_K_XL** と **UD-Q8_K_XL** に対応しました。各項目から対応するファイルが選択されます。llama-server で起動し、画像を入力する場合は対応する mmproj も読み込んでください。

Apple Silicon では Swift ネイティブの mlx-server で **4-bit MLX** と **8-bit MLX** を利用できます。モデルディレクトリ全体をダウンロードし、自動判別で起動すると、テキストと画像を処理できます。重みはそれぞれ約 17.31 GB、18.09 GB で、エキスパートには混合精度を使用します。推論には追加のメモリが必要です。重みはインストーラーとは別にダウンロードしてください。

### 検証と更新

M4 Pro（64 GiB）で両 MLX 版の全重みの SHA-256 を照合し、テキスト生成、赤い画像の認識、SSE ストリーミングを確認しました。macOS での GGUF 実推論には IQ4_NL と Q8_0 mmproj を使用しました。Inkling の対応範囲は単一マシンでの標準デコードです。このモデルの Fast GGUF、TCP Ring／RDMA、DFlash、MTP は未対応です。本リリースの Windows／Linux インストーラーを用いた実機での推論は未検証です。

「システム設定 → このアプリについて」から更新して再起動するか、以下の macOS Apple Silicon 用 DMG、Windows x64 用 MSI、Linux x64 用 ZIP をダウンロードしてください。Linux では初回インストール時に同梱の Vulkan エンジンをビルドします。ダウンロードしたファイルは SHA256SUMS で照合できます。[モデルガイド](https://github.com/VaderChen/Tanpopo/blob/v1.26.1123-build-1005/docs/INKLING2-MINI.md) · [検証記録](https://github.com/VaderChen/Tanpopo/blob/v1.26.1123-build-1005/docs/validation/inkling2-mini-smoke-2026-11-23.json)

## 한국어

### Inkling-2-Mini

모델 다운로드 화면의 자주 사용하는 모델 목록에서 **30B급**을 열어 양자화 형식을 선택하세요. GGUF는 기존 **IQ4_NL**과 함께 Unsloth의 메인라인 호환 **UD-Q4_K_XL**, **UD-Q8_K_XL**을 제공합니다. 항목을 선택하면 해당 파일명이 지정됩니다. llama-server로 실행하고, 이미지 입력에는 모델에 맞는 mmproj를 함께 불러오세요.

Apple Silicon에서는 네이티브 Swift mlx-server로 **4-bit MLX**와 **8-bit MLX**를 실행할 수 있습니다. 모델 디렉터리 전체를 내려받고 자동 감지로 시작하면 텍스트와 이미지를 처리할 수 있습니다. 가중치는 각각 약 17.31 GB, 18.09 GB이며 두 모델 모두 혼합 정밀도 전문가 가중치를 유지합니다. 추론에는 추가 메모리가 필요합니다. 가중치는 설치 파일과 별도로 다운로드하세요.

### 검증 및 업데이트

M4 Pro(64 GiB)에서 두 MLX 모델의 전체 가중치 SHA-256을 확인하고 텍스트 생성, 빨간색 이미지 인식, SSE 스트리밍을 검증했습니다. macOS의 GGUF 추론 검증에는 IQ4_NL과 Q8_0 mmproj를 사용했습니다. Inkling은 단일 장비의 표준 디코딩을 지원합니다. 이 모델의 Fast GGUF, TCP Ring/RDMA, DFlash 및 MTP는 지원 범위에 포함되지 않습니다. 이번 Windows 및 Linux 설치 파일의 실기기 종단 간 추론은 검증하지 않았습니다.

시스템 설정의 앱 정보에서 업데이트 후 다시 시작하거나, 아래의 macOS Apple Silicon용 DMG, Windows x64용 MSI 또는 Linux x64용 ZIP을 다운로드하세요. Linux는 최초 설치 시 동봉된 Vulkan 엔진을 빌드합니다. SHA256SUMS로 다운로드한 파일을 확인할 수 있습니다.
