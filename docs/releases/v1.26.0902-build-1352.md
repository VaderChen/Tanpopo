## 更新重點

- 新增手動效能校準：可複選模型、依 GGUF／MLX 過濾，並自動選擇適用的 Server 與啟動配置。未載入模型也能開啟；已載入且相容的配置會重用。
- 校準對話框逐項顯示 3 組配置、每組 3 次測試的進度與完成狀態，公開速度、平均值、中位數及建議配置；保存最佳中位數配置，供相同硬體、Runtime、模型及啟動參數的後續啟動自動套用。
- 「模型來源」更名為「模型來源與設定」，效能校準移入此頁並對新安裝預設開啟；不會在首次載入模型時自行測試。
- 新增預設關閉的記憶體壓力保護：啟動前估算需求，必要時降低 Context／Batch／Prefill、停用推測解碼，或拒絕超出可用預算的啟動。這不是執行期記憶體硬上限或持續 OOM 監控。
- Fast GGUF 支援完整獨立啟動資產及模型列表 fallback；原始 GGUF 移除後，完整的 Fast GGUF 仍可由 mlx-server 重新載入。「轉換後移除原 GGUF」預設關閉且需確認，僅在完整性與模型載入驗證成功後刪除來源。
- 下載中心新增 Repository 搜尋、下載數／讚數／字母排序、GGUF 檔名下拉選單與重新掃描。預設優先選 `Q4_0`，沒有則選排序第一項。選用後關閉搜尋視窗，保留同一頁面的查詢紀錄。
- 新增持久化「我的最愛」，可收藏模型格式、Repository 與 Revision；移除收藏前顯示確認，內建項目回到常用清單，不刪除已下載模型。
- 系統設定頁的開關、下拉選單與配色改變後自動儲存，原儲存按鈕保留。自動儲存不連帶提交未完成的文字欄位，失敗時還原選項並提示錯誤；「清除 Access Token」改為立即執行的確認按鈕。
- 修正 Gemma 4 GGUF 的逐層 KV heads／K=V 權重配置、`<channel|>` 思考通道解析，以及校準的 conversion-preflight 欄位錯誤；改善多語介面、搜尋視窗與捲動間距。

## 使用注意事項

- Fast GGUF 是 Apple Silicon／mlx-server 的內部格式，不是 llama.cpp 可載入的 GGUF。fallback 目前不支援內嵌 MTP；改用 llama.cpp 或重新轉換仍需原始 GGUF。
- 效能校準會切換測試配置，必要時重啟 Runtime；整批完成後恢復原模型或未載入狀態。結果僅代表當次硬體、模型與測試工作負載。
- 自動儲存限於系統設定；不會自行啟動模型、下載、效能校準或反向代理。危險操作與安全前置條件仍需明確確認。
