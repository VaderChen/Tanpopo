## Highlights

- Added manual performance calibration with multi-model selection, GGUF/MLX filtering, and automatic selection of a compatible server and launch configuration. The dialog can open without a loaded model and reuses compatible configurations that are already loaded.
- Calibration compares three configurations with three runs each, showing per-test progress and completion status. Results include individual speeds, averages, medians, and recommended settings. The configuration with the best median is saved and automatically applied on later launches with the same hardware, runtime, model, and launch parameters.
- Renamed **Model sources** to **Model sources and settings** and moved performance calibration there. Calibration is enabled by default for new installations, but tests never start automatically on the first model load.
- Added opt-in memory pressure protection. Before launch, it estimates memory requirements and may reduce Context/Batch/Prefill, disable speculative decoding, or reject a launch that exceeds the available budget. This is not a runtime memory cap or continuous OOM monitor.
- Added standalone startup assets and model-list fallback for Fast GGUF. Complete Fast GGUF packages remain reloadable through mlx-server after the original GGUF is removed. **Remove original GGUF after conversion** is off by default, requires confirmation, and removes the source only after package integrity and successful model loading have been verified.
- Added repository search, sorting by downloads, likes, or name, a GGUF filename dropdown, and rescanning in the download center. The default selection prefers `Q4_0`; if unavailable, it uses the first sorted entry. Selecting a result closes the search dialog while preserving the query and results on the same page.
- Added persistent **My favorites** for model format, repository, and revision. Removing a favorite requires confirmation; built-in entries return to the popular-model list, and downloaded models are not deleted.
- Switches, dropdowns, and theme choices in System settings now save automatically while retaining the original Save buttons. Autosave does not submit unfinished text fields; failed saves restore the option and display an error. **Clear Access Token** is now a button that clears the saved token immediately after confirmation.
- Fixed per-layer KV-head and K=V weight handling for Gemma 4 GGUF, `<channel|>` reasoning-channel parsing, and invalid fields in calibration conversion-preflight requests. Improved multilingual layouts, the search dialog, and scrolling spacing.

## Usage notes

- Fast GGUF is an internal Apple Silicon/mlx-server format, not a GGUF file that llama.cpp can load. Embedded MTP is not currently supported through the fallback. Using llama.cpp or converting again still requires the original GGUF.
- Calibration switches test configurations and restarts the runtime when necessary. After the batch, it restores the original model or unloaded state. Results apply to the hardware, model, and workload used for that calibration.
- Autosave applies only to System settings. It does not automatically start models, downloads, calibration, or reverse proxy connections. Required confirmations and security prerequisites remain in place.
