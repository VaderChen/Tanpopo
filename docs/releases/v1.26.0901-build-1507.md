## Highlights

- Added native MLX MTP speculative decoding for compatible Target/Draft pairs, plus embedded MTP prediction-layer loading for compatible GGUF models.
- Added a complete Fast GGUF Mode 1/2/3 workflow: balanced default, higher-accuracy INT8, and fastest INT4 strategies.
- Added three-run performance testing with average and median throughput, and a long-output test that requires at least 500 output tokens.
- Linux packages now install missing Vulkan build dependencies, configure GPU device permissions, provide `build-llama-server.sh`, and build a Vulkan-enabled llama.cpp runtime when a matching prebuilt runtime is unavailable.
- Added authenticated Linux ZIP updates with archive validation, atomic replacement, and automatic service restart.
- Fixed Linux GPU utilization reporting by falling back to the DRM `gpu_busy_percent` interface when ROCm tools are unavailable.
- Fixed persistent **Remember me** sessions across service restarts; changing the administrator credentials invalidates existing persistent cookies.
- Improved the multilingual interface, enlarged the chat workspace, cleaned up empty model lists, and standardized alphabetized GGUF, MLX, and mmproj selectors as `model name (directory name)`.
- Release update checks now compare build numbers, allowing multiple stable releases on the same day.
